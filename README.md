# Закрывающий тег

Интерактивная страница-дневник о пути в веб-разработке, сверстанная в рамках проектной работы Яндекс Практикума. Проект сочетает ретро-эстетику пиксельной графики, плавную резиновая верстку и сложные CSS-анимации.

🔗 **[Посмотреть демо на GitHub Pages]

---

## 🛠 Стек технологий

* **HTML5** — семантическая разметка, работа с векторной графикой (`<svg>`) и нативным модальным окном (`<dialog>`).
* **CSS3** — Flexbox и Grid Layout, кастомные свойства (CSS-переменные), вариативные шрифты (`Inter`), резиновая типографика и отступы через функцию `clamp()`.
* **Анимации и эффекты** — `@keyframes`, плавные переходы (`transition`), CSS-фильтры (`filter`), режимы наложения (`mix-blend-mode`).
* **JavaScript** — базовые скрипты для интерактивности кнопок лайка и открытия/закрытия модального окна.

---

## ✨ Основной функционал

* **Адаптивная и резиновая верстка:** интерфейс корректно отображается на экранах от `375px` до `1440px` и шире.
* **Интерактивные карточки:** у каждой карточки с воспоминанием есть свой уникальный CSS-фильтр (сепия, размытие, инверсия, поворот оттенка и др.).
* **Анимация лайков:** клик по иконке сердца или кнопке `Like` запускает поэтапную SVG-анимацию заливки и масштабирования.
* **Микроанимации кнопок:** при наведении на кнопки срабатывает плавная заливка фона с инверсией цвета текста через `mix-blend-mode: difference`.
* **Модальное окно:** кнопка «Сохранить на память» вызывает диалоговое окно с предупреждением о необходимости вставить дискету.

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone 
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd [название-репозитория]
   ```
3. Откройте файл `index.html` в любом современном браузере или запустите через расширение **Live Server** в VS Code.

